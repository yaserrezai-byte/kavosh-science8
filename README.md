# کاوش | داشبورد علوم هشتم
نسخهٔ اولیهٔ ایستا، راست‌به‌چپ و مناسب موبایل با ۹ فصل موجود در فایل ارسالی. همهٔ فصل‌ها درس خلاصه و پرسش نمونه دارند؛ فصل اول نمایش متحرک و مطالب بیشتری دارد. شکل‌های کتاب در PDF موجودند. انیمیشن اختصاصی همهٔ فصل‌ها، آزمون جامع، و ایجنت‌های گفت‌وگویی واقعی هنوز ساخته نشده‌اند. محتوا باید قبل از استفادهٔ رسمی توسط دبیر بازبینی شود.

## اجرا و انتشار
در این پوشه `python3 -m http.server 8000` را اجرا کنید. برای انتشار پوشه را در میزبانی ایستا بارگذاری کنید. فایل‌های book.pdf و content.js باید کنار index.html باشند. پیش از انتشار عمومی، مجوز انتشار فایل کتاب را بررسی کنید. بعضی مرورگرها یا پیش‌نمایش‌های محدود PDF تعبیه‌شده را نمایش نمی‌دهند؛ از پیوند باز کردن کتاب استفاده کنید.

## ادامه: ایجنت‌های واقعی
نیازمند سرویس هوش مصنوعی، سرور امن، احراز هویت و محافظت از کودکان است. کلید ارائه‌دهنده باید فقط در متغیر محیطی سمت سرور باشد. پاسخ‌ها را به محتوای بازبینی‌شدهٔ کتاب با ارجاع صفحه متصل و به‌طور مستقل ارزیابی کنید.
